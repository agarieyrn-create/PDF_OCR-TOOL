## 1. 初回セットアップ

### 1-1. Python のインストール確認

コマンドプロンプト（Windows）またはターミナル（Mac）を開いて確認します。

```
python --version
```

`Python 3.10.x` 以上が表示されればOKです。  
表示されない場合は https://www.python.org/ からインストールしてください。

---

### 1-2. 必要ライブラリのインストール

`tool` フォルダに移動してから実行します。

```
cd tool
pip install PyMuPDF openpyxl pytesseract pdf2image Pillow
```

**ドラッグ&ドロップも使いたい場合（任意）**

```
pip install tkinterdnd2
```

---

### 1-3. Tesseract OCR のインストール（画像PDFを処理する場合のみ）

| OS | インストール方法 |
|----|----------------|
| Windows | https://github.com/UB-Mannheim/tesseract/wiki からインストーラをダウンロード。「Japanese」言語パックにチェックを入れること |
| Mac | `brew install tesseract tesseract-lang` |
| Linux | `sudo apt install tesseract-ocr tesseract-ocr-jpn` |

> **テキストPDFのみ使う場合は不要です。**

---

## 2. ツールの起動

### Windows の場合

`tool` フォルダ内の **`起動.bat`** をダブルクリック

```
tool/
└── 起動.bat  ← これをダブルクリック
```

---

### Mac の場合

初回のみターミナルで以下を実行（実行権限の付与）

```
chmod +x 起動.command
```

以降は **`起動.command`** をダブルクリック

---

### コマンドで起動する場合（共通）

```
cd tool
python gui.py
```

## 3. 基本的な使い方

### STEP 1 ── PDFを追加する

**方法A: ボタンで選ぶ**

画面左上の **「📂 ファイル追加」** をクリック → PDFファイルを選択

**方法B: フォルダごと追加する**

**「📁 フォルダ選択」** をクリック → フォルダを選ぶと中のPDFが全部追加される

**方法C: ドラッグ&ドロップ**（tkinterdnd2 インストール済みの場合）

PDFファイルを画面左のリストエリアにドロップ

---

### STEP 2 ── 処理を開始する

**「▶ 処理開始」** ボタンをクリック（または **F5** キー）

画面右上の進捗バーが動き、左のリストに処理状況がリアルタイムで表示されます。

```
待機 → 処理中 → 完了
```

---

### STEP 3 ── 結果を確認する

処理が終わると右側のプレビューに結果が表示されます。

- **「ヘッダ」タブ** ── 各PDFの基本情報（日付・金額・会社名・番号）
- **「明細」タブ** ── 品名・数量・単価・金額の行データ

---

### STEP 4 ── Excel に出力する

**「💾 Excel出力」** ボタンをクリック（または **Ctrl+S**）

保存先とファイル名を選んで「保存」→「ファイルを開きますか？」でそのまま開けます。

---

## 4. 処理結果の見方

### 左パネル（ファイルリスト）の状態色

| 色 | 状態 | 意味 |
|----|------|------|
| グレー | 待機 | 処理待ち |
| 青 | 処理中 | 読み込み・抽出中 |
| 緑 | 完了 | 正常に分類・抽出できた |
| オレンジ | 不明 | 種別を判定できなかった |
| 赤 | エラー | PDFの読み込みに失敗した |

---

### 「不明」になったときの対処

キーワードが少なくて分類できなかった場合です。  
→ [6. 分類ルールのカスタマイズ](#6-分類ルールのカスタマイズ) を参照してください。

---

### 「エラー」になったときの対処

- パスワードつきPDFは処理できません
- 壊れたPDFファイルの可能性があります
- 画像PDFの場合、Tesseract OCR が未インストールだと失敗します

詳細は画面右下の **ログパネル** を確認してください。

## 5. Excel ファイルの出力

出力される Excel ファイルには **2つのシート** があります。

### シート①「ヘッダ」

| 列名 | 内容 |
|------|------|
| ファイル名 | 元のPDFファイル名 |
| 種類 | 請求書 / 納品書 / 発注書 / 不明 |
| 日付 | 請求日・納品日・発注日 など |
| 金額 | 合計金額 |
| 会社名 | 請求先・納品先 などの会社名 |
| 番号 | 請求書番号・伝票番号 など |

---

### シート②「明細」

| 列名 | 内容 |
|------|------|
| ファイル名 | 元のPDFファイル名 |
| 行番号 | 明細の行番号（1から始まる） |
| 品名 | 商品名・サービス名 |
| 数量 | 個数 |
| 単価 | 1個あたりの金額 |
| 金額 | 小計金額 |

## 6. 分類ルールのカスタマイズ

`tool/rules/` フォルダの JSON ファイルを編集することで分類精度を上げられます。

```
tool/rules/
├── invoice.json   ← 請求書のキーワード
├── delivery.json  ← 納品書のキーワード
└── order.json     ← 発注書のキーワード
```

### 編集例（invoice.json）

```json
{
  "classification_keywords": [
    "請求書",
    "ご請求",
    "請求金額",
    "支払期限",
    "振込先",
    "ここに追加したいキーワード"  ← ← ←
  ],
  ...
}
```

> **ポイント:** よく使う言葉を追加するだけでスコアが上がり、分類精度が向上します。  
> ファイルを保存したら次回の処理から反映されます。

## 7. 設定の変更

メニューバーの **「設定」→「設定を編集」** から変更できます。

| 項目 | 説明 | 初期値 |
|------|------|--------|
| 入力フォルダ | PDFを置く場所（CLI用） | `input` |
| 出力フォルダ | Excelの保存先（CLI用） | `output` |
| 出力ファイル名 | Excelのファイル名 | `result.xlsx` |
| OCR言語 | `jpn`（日本語）または `jpn+eng`（日英混在） | `jpn+eng` |
| OCR DPI | 画像の解像度。精度重視なら `400`、速度重視なら `200` | `300` |

## 8. うまくいかないときは

### Q. 起動しない

```
python --version  # Python 3.10以上か確認
pip install PyMuPDF openpyxl  # ライブラリを再インストール
```

---

### Q. 金額や日付が空欄になる

PDF のレイアウトが特殊な場合があります。  
`rules/*.json` に該当PDFで使われているキーワードを追加してください。

例：金額の前に「お支払金額」と書かれている場合

```json
"amount": ["請求金額", "合計金額", "お支払金額"]  ← 追加
```

---

### Q. 明細が抽出されない

明細の開始キーワードが認識されていない可能性があります。  
該当 PDF のテーブルヘッダに書かれている言葉を `detail_start_keywords` に追加してください。

```json
"detail_start_keywords": ["品名", "品目", "商品名", "内容"]  ← 追加
```

---

### Q. OCR の精度が低い

1. 設定で `ocr_dpi` を `300` → `400` に上げる
2. PDF が傾いている場合は、先にスキャンし直すと改善することがあります

---

### Q. ログを確認したい

画面右下のログパネルに処理の詳細が表示されます。  
また `tool/logs/log.txt` にも全ログが保存されています。
