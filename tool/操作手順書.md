## 1. 初回の準備

### Windows の場合

```
① ZIP ファイルを右クリック →「すべて展開」
② 展開されたフォルダを開く
③ PDF_OCR_Tool.exe をダブルクリック
```

> フォルダはどこに置いても動きます（デスクトップ・Dドライブなど）

---

### Mac の場合

```
① ZIP ファイルをダブルクリックで解凍
② 展開されたフォルダを開く
③ PDF_OCR_Tool をダブルクリック
```

> 初回起動時に「開発元を確認できない」と表示される場合:  
> **システム環境設定 → セキュリティとプライバシー → 「このまま開く」**

---

### フォルダ構成（変更しないでください）

```
PDF_OCR_Tool/
├── PDF_OCR_Tool.exe   ← 起動ファイル
├── config.json        ← 設定ファイル
├── rules/             ← 分類ルール（カスタマイズ可）
│   ├── invoice.json
│   ├── delivery.json
│   └── order.json
├── input/             ← PDFをここに入れる（CLIモード用）
├── output/            ← Excelの出力先（CLIモード用）
└── logs/              ← 処理ログ（自動生成）
```

> **⚠ exe ファイルだけ別の場所に移すと動きません。フォルダごと移動してください。**

## 2. 基本的な使い方

### STEP 1 ── ツールを起動する

`PDF_OCR_Tool.exe` をダブルクリックします。

---

### STEP 2 ── PDF を追加する

**方法A：ボタンで選ぶ**
画面左上の **「📂 ファイル追加」** → PDFを選択

**方法B：フォルダごと追加する**
**「📁 フォルダ選択」** → フォルダを選ぶと中のPDFが全部追加される

**方法C：ドラッグ&ドロップ**
PDFファイルを画面左のリストにドロップ

---

### STEP 3 ── 処理を開始する

**「▶ 処理開始」** ボタンをクリック（または **F5** キー）

画面右上の進捗バーが動き、左のリストにリアルタイムで状態が表示されます。

---

### STEP 4 ── Excel に保存する

**「💾 Excel出力」** ボタンをクリック（または **Ctrl+S**）

保存先とファイル名を指定して「保存」→ そのまま開くか選べます。

---

## 3. 処理結果の見方

### ファイルリストの状態（色）

| 色 | 状態 | 意味 |
|----|------|------|
| グレー | 待機 | 処理待ち |
| 青 | 処理中 | 読み込み・解析中 |
| **緑** | **完了** | **正常に分類・抽出できた** |
| オレンジ | 不明 | 請求書/納品書/発注書を判定できなかった |
| 赤 | エラー | PDFの読み込みに失敗した |

---

### 右側のプレビュータブ

| タブ | 内容 |
|------|------|
| **ヘッダ** | 各PDFの基本情報（日付・金額・会社名・番号） |
| **明細** | 品名・数量・単価・金額の行データ |

列のタイトルをクリックするとその列で並び替えができます。

---

### ログパネル（右下）

処理の詳細が表示されます。エラーが出た場合は赤字で確認できます。

## 4. Excel ファイルの内容

出力される Excel は **2つのシート** で構成されています。

### シート①「ヘッダ」

| 列 | 内容 |
|----|------|
| ファイル名 | 元のPDFファイル名 |
| 種類 | 請求書 / 納品書 / 発注書 / 不明 |
| 日付 | 請求日・納品日・発注日 など |
| 金額 | 合計金額（数値） |
| 会社名 | 請求先・納品先 などの会社名 |
| 番号 | 請求書番号・伝票番号 など |

### シート②「明細」

| 列 | 内容 |
|----|------|
| ファイル名 | 元のPDFファイル名 |
| 行番号 | 明細の連番（1から） |
| 品名 | 商品名・サービス名 |
| 数量 | 個数 |
| 単価 | 1個あたりの金額 |
| 金額 | 行の小計金額 |

## 5. 分類がうまくいかないときの調整

「不明」と判定されるPDFがある場合、`rules/` フォルダのJSONファイルにキーワードを追加することで改善できます。

### 手順

1. `rules/` フォルダ内の該当するファイルをメモ帳で開く
   - 請求書 → `invoice.json`
   - 納品書 → `delivery.json`
   - 発注書 → `order.json`

2. `classification_keywords` のリストにキーワードを追記する

**例：`invoice.json` に「お支払い」を追加する場合**

```json
{
  "classification_keywords": [
    "請求書",
    "ご請求",
    "請求金額",
    "支払期限",
    "振込先",
    "お支払い"   ← ここに追加（最後の行にはカンマ不要）
  ],
  ...
}
```

3. 保存してツールを再起動する（再起動なしでもOK）

---

### 金額や日付が空欄になる場合

`rules/` の `header` セクションにそのPDFで使われているキーワードを追加します。

```json
"header": {
  "amount": ["請求金額", "合計金額", "お支払金額"],  ← 追加
  "date":   ["請求日", "発行日", "ご請求日"],         ← 追加
  ...
}
```

## 6. 設定の変更

メニューバー **「設定」→「設定を編集」** から変更できます。

| 項目 | 説明 | 初期値 |
|------|------|--------|
| 入力フォルダ | PDF一括処理フォルダ | `input` |
| 出力フォルダ | Excel保存先 | `output` |
| 出力ファイル名 | Excelのファイル名 | `result.xlsx` |
| OCR言語 | `jpn`（日本語）/ `jpn+eng`（日英混在） | `jpn+eng` |
| OCR DPI | 精度重視: `400`、速度重視: `200` | `300` |

## 7. よくある質問

**Q. 起動しない / 画面が出ない**
> フォルダ全体が揃っているか確認してください。exe だけを別の場所に移すと動きません。

**Q. 「不明」と表示されて分類されない**
> `rules/*.json` にそのPDFで使われているキーワードを追加してください（§5参照）。

**Q. 金額や会社名が空欄になる**
> レイアウトが特殊なPDFの場合があります。`rules/*.json` の `header` にキーワードを追加してください。

**Q. 画像スキャンしたPDFが処理できない**
> 画像PDFのOCR処理には **Tesseract OCR** の別途インストールが必要です。  
> テキストPDFであれば追加インストール不要です。

**Q. 処理に時間がかかる**
> 画像PDFのOCR処理は時間がかかります。`config.json` の `ocr_dpi` を `200` に下げると速くなります（精度は落ちます）。

**Q. エラーログを確認したい**
> `logs/log.txt` に全ての処理ログが保存されています。
