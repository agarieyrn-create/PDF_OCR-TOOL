# ビルド手順（開発者向け）

Python 不要の配布用 exe を作成する手順です。

---

## 前提条件

- Python 3.10 以上がインストール済み
- `tool/requirements.txt` のライブラリがインストール済み

```bash
pip install PyMuPDF openpyxl pytesseract pdf2image Pillow
pip install pyinstaller
```

---

## Windows 向けビルド

```
build/
└── build_windows.bat  ← これをダブルクリック
```

完了すると以下が生成されます：

```
build/
├── dist/PDF_OCR_Tool/     ← 動作確認用（フォルダ一式）
└── PDF_OCR_Tool_Windows.zip  ← 配布用ZIP
```

---

## Mac 向けビルド

```bash
cd build
./build_mac.sh
```

完了すると以下が生成されます：

```
build/
├── dist/PDF_OCR_Tool/    ← 動作確認用
└── PDF_OCR_Tool_Mac.zip  ← 配布用ZIP
```

---

## 配布パッケージの中身

```
PDF_OCR_Tool/
├── PDF_OCR_Tool.exe   起動ファイル（Macは拡張子なし）
├── config.json        設定（ユーザーが編集可能）
├── rules/             分類ルール（ユーザーが編集可能）
│   ├── invoice.json
│   ├── delivery.json
│   └── order.json
├── input/             PDF投入フォルダ
├── output/            Excel出力先
└── logs/              処理ログ（自動生成）
```

> `rules/` と `config.json` はユーザーが編集できるよう exe の外に配置しています。

---

## アイコンを設定する場合

1. `build/` フォルダに `icon.ico`（Windows）または `icon.icns`（Mac）を置く
2. `pdf_ocr_tool.spec` の `icon=None` を `icon="icon.ico"` に変更
3. 再ビルド

---

## トラブルシューティング

**ビルドは成功したが起動しない**
- `dist/PDF_OCR_Tool/` フォルダ内で直接 exe を実行して、エラーメッセージを確認
- `pdf_ocr_tool.spec` の `hiddenimports` に不足しているモジュールを追加

**fitz 関連エラー**
```
pip install --upgrade PyMuPDF
pyinstaller pdf_ocr_tool.spec --noconfirm --clean
```

**antivirus に誤検知される**
- UPX 圧縮を無効化: spec ファイルの `upx=True` を `upx=False` に変更して再ビルド
